## Requirements

Name of Person requires PHP 8.4 or later with the `mbstring` extension. The [Eloquent cast](basic-usage/eloquent-casts) works with Laravel 13 and needs its `illuminate/database` package, which Laravel applications already include.

## Install the package

Install the package with Composer:

```bash
composer require hosmelq/name-of-person
```
