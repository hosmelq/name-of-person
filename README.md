# Name of Person

Name of Person formats people's names in PHP as full, familiar, abbreviated, and sorted names,
initials, mention handles, and possessives, and casts them on Eloquent models.

```bash
composer require hosmelq/name-of-person
```

Read the [full documentation](https://hosmelq.com/docs/name-of-person).

## Development

Run the test suite with:

```bash
composer test
```
